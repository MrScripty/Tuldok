## Bounded proposed contract

One locally chosen native ZIP containing 1–100 image-detection records only;
8 MiB archive, 16 MiB expanded, stored unencrypted entries, no extraction or URL
fetching. Validate exact native manifest fields and three COCO projections,
including vocabulary, global image indices, box/category associations, negative
images and empty detection-only records.jsonl. Require complete normalized RGB
PNGs, oriented geometry and measured byte/pixel hashes. Boxes retain the existing
oriented pixel-edge xywh validator. Unsupported/malformed bundles fail preparation
without writes; later per-record duplicate/storage failures use existing outcomes.

Prepared process-local signed rows include consumed PNG input and measured
archive/manifest/COCO/asset evidence; at most 3 MiB per decoded row and 16 MiB
combined prepared tokens. Historical identity, hashes, review, rights and omitted
originals remain declared upstream evidence. New IDs, actual input hashes, unknown
rights, draft review, revision one and initial history belong to existing owners.
No inherited approval. Preserve declared family links without claiming the native
manifest includes unselected upstream bridges. The consumed export split becomes a fixed local source split; reject conflicts within retained selected links and with existing/deleted local lineage. The original upstream source split remains declared.

Dataset remains the only image original/normalization/filesystem owner; Workbench
owns initial task/annotation/history within its existing acquisition transaction.
The importer owns native decoding and prepared evidence. The UI schedules rows
and exposes outcomes, Stop and read-only uncertain-result inspection, preserving
dirty editors, exact selections and frozen releases. No replay after uncertain
writes, no job queue, editor expansion or second image store.

## Verification and scope limits

Use fresh tiny fixtures from the actual existing exporter, not invented COCO.
Prove roundtrip PNG geometry/boxes (including negative images), draft barriers,
explicit review, exact selection and immutable re-export. Exercise malformed
hash/COCO/path/axis bounds/nonfinite data, unsupported tasks, request-marker and
pixel duplicates, restart expiration, per-record storage rollback and response
loss. Run focused owner/controller/real browser checks and the registered aggregate.
Generated archives, screenshots and receipts stay outside Git.

Reuse the accepted real Rheon pilot at exact producer
`fee7b4a139574f87b259796b1ba8698a41d31ac1`; do not run another pilot, repin, download
models or assert training quality. This feature creates reviewable detection
drafts from an existing transport, not a qualified model or scientific dataset.
