## Contract and acceptance

Inputs exactly mesh.ply and mesh.json; no paths or archives. PLY ASCII 1.0, xyz float/double properties (each named native dtype retained), optional complete nx/ny/nz float/double properties retained, then face list uchar int vertex_indices. Comments allowed within bounded header. Triangles only; no unknown attributes, binary, polygons, transformations, triangulation, normals normalization or scene framework. Preserve both raw files byte-exactly. 2 MiB geometry, 32 KiB JSON, 16 KiB header, 1 KiB line, 20,000 vertices, 40,000 triangles, request 3 MiB, total selected immutable assets 40 MiB shared with sequences. Native finite representability, no nonzero underflow; coordinate magnitude at most 1e12 declared units for finite stable derived bounds/cross products. Each face has exactly three distinct valid integer indices, nonzero native area, no duplicate unordered faces. Open surfaces allowed; topology validity is not watertightness/physics suitability.

Tuldok-owned sidecar format tuldok_mesh_v1, geometry file exact mesh.ply, geometry_bytes and lowercase SHA256, units m/cm/mm, coordinate_system {frame,handedness right|left,up_axis x|y|z}; no axis conversion. Provenance {source,revision,license,description} bounded strings. Strict duplicate-free finite JSON and exact fields, file digest/length before PLY parsing. Declared provenance and license are not verified rights or scientific qualification. Failures use existing WorkbenchError and HTTP invalid/conflict/unavailable projection.

One record kind mesh/task mesh_geometry, initially draft/rights unknown. Existing human note review/history/rights correction and revision CAS remain authoritative; program verification cannot approve meshes. Protected groups mesh-source:<sha>, mesh-family:<canonical native xyz/index/units/frame digest> immutable; declared user groups and parent IDs remain available. Canonical family ignores comments/provenance/normals/dtypes where native geometry equivalent, canonical zeros. Whole mesh, sequence trajectories, connected parents/groups indivisible. User still owns grouping related transformed/remeshed geometry.

Metadata: header dtype/property names, vertex/triangle counts, bounds in declared units, provided-normal presence, declared coordinate/provenance data, file hashes, explicit scope. No full vertex arrays in collection listings. Inspector endpoint reloads and revalidates bounded immutable asset, returns at most first 512 triangle vertices for XY/XZ/YZ wireframe inspection (sample clearly labeled); generation/current-record guard prevents stale projection; review note has existing editor ownership. SVG axes/units and visible native coordinate frame. Raw ZIP download unchanged.

Acceptance tests: actual small authored ASCII tetrahedron and open surface files (not mocked parser results), exact raw/native roundtrip, malformed hash before parse, truncation, unknown/wrong axes/schema/dtypes, invalid faces/nonfinite/underflow/caps, atomic asset/record/history failures; both original image/text and sequence schema migration preserving records/indexes/rights/history with rollback/idempotence/unexpected-schema refusal; immutable family and sequence-parent split closure; human-only export, exact frozen mixed assets and tamper/stale rejection; Chromium real import/inspection/note/review/export/reload, unsaved editor/selection/repeated-submit and stale preview ownership, narrow layout and JPEG85 captures.
