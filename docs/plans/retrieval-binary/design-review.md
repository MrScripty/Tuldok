# Design review record

The concise contract plan preceded implementation. Independent source, consumer and UI reviews admitted the separate binary task/profile with explicit conditions: fixed text split retention through existing owners, stable upstream anchors across releases, deliberate reference refresh after document review, whole-bundle atomic import, and actual external parser retention of all three grades. Source and consumer refinements were incorporated before runtime qualification.

The released ir_measures0.4.3 parser was inspected through official package reads and probed before selecting source-loaded unchanged `Qrel`/`read_trec_qrels` definitions. Full package/provider/metric execution was excluded. Its exact source/pins/license are retained alongside the independent consumer checker.

During implementation independent backend review found and reproduced two defects: exponent-encoded nonfinite JSON and erasure of imported acquisition evidence during generic owned verification. Both were corrected and independently rechecked before exact-commit admission. Browser development found a Clear-selection test race and actual narrow judgment-reference overflow; the test now awaits owner idle state and the scoped binary CSS wraps exact refs.

Machine review/checkpoint receipts are outside the source repository under `/workspace/retrieval-binary-qualification`; final handoff binds exact source and fresh qualification. Preliminary executions are retained separately and are not relabeled as final committed-source results. Main and the completed b14 candidate remain frozen; no Git credential retry or publication route is used.
