# Design admission

Independent source and consumer reviews admitted the point-only scope before
implementation. Conditions are mandatory complete family proof, immutable
captured release bytes, exact closed schemas and source associations, actual
pinned native-property comparisons, fresh whole-cloud arrays/deep metadata,
pickle-free bounded atomic output and input alias refusal. Every proofless
release is refused, including a legacy single-split packet. Mesh support remains
deferred because its wider decimal domain differs from the demonstrated reader.

Reuse the existing family verifier without changing sequence legacy semantics.
Point-only canonical exports gain the existing proof convention; sequence and
mixed behavior remain unchanged. Strict contiguous local ZIP headers supplement
the current central-directory preflight. This is declared graph/reader/data
preparation qualification, not authenticated lineage, semantic labels, model
quality, training or simulation qualification.

Exact review/runtime handoff receipts stay outside Git under
`/workspace/native-pointcloud-consumer-qualification`. Accepted83f/b14 source,
evidence and frozen main remain separate preserved checkpoints. No publication
or denied credential retry is part of this milestone.
