The actual browser revokes a real session before export and before ordinary Run
detail, prediction and model-evidence reads. It also holds an existing checkpoint
action, allows the rerendered retained query to succeed, then revokes/releases the
checkpoint read; both private metric grid and retained graph disappear. A shared

The /workspaces meta CSP precedes every asset. Script execution is self-only;
inline scripts and runtime code generation remain blocked. Existing application
inline CSS remains allowed. Browser acceptance collects unexpected violations
and verifies blocked Function construction with the DevTools CSP bypass disabled.
The isolated renderer additionally proves compatibility with self-only styles.
