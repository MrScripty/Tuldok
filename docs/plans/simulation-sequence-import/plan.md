# Bounded simulation sequence import

Base: Tuldok 309a87d753f97b245385f8d6db20353ab536a836. Main remains 2fc4a46f12d73a0fa467d5482f68edb83d6df6af. Local candidate only.

Producer contract: MrScripty/Rheon draft PR 20, exact fee7b4a139574f87b259796b1ba8698a41d31ac1, still unmerged. Read exporter, independent importer, Rust writer, source-derived tests and docs using the authorized GitHub connector. Contract changes require root review coordination; no alternate schema acceptance.

Design proposed before implementation: add generic immutable sequence assets to Workbench, a sequence kind and sequence_transport task. A separate SQLite asset table stores exact run.json and frames.jsonl bytes, together with metadata and a nine-entry frame index. Same Dataset lock/transaction owns asset, record, initial history publication: validation happens before mutation, and any insertion/history failure rolls back everything. Existing image/text tables retain identities and rows through an additive kind-constraint migration. No external storage or 3D editor.

Rheon adapter uses the exact source-pinned stdlib validation contract, including hash-before-frame-parse, geometry, native finite types, stamps, accepted intervals, fixture associations and diagnostics. Limits: 64 KiB manifest, 2 MiB frames, 256 KiB line, exactly 512 cells and nine frames. Accept only two selected files with exact names through bounded base64 JSON; never read client filesystem paths or extract uploaded archives. Keep raw arrays and bytes unchanged, named MAC components/shapes/types/units, pressure interval meaning and declared producer provenance. Contract validation is technical evidence, never human review or training qualification.

Initial records are draft, rights default unknown. Human review saves a sequence-specific note via existing optimistic revisions/history/rights owners. Auto-derived trajectory and constructor-family protected groups cannot be removed. Family identity hashes geometry/config/constructor fields without volatile stamps or producer path/toolchain, so equivalent initial conditions cannot cross splits. One whole trajectory is one selected record; frame indices are inspection only. Existing connected-family allocator includes sequences. Canonical release copies an exact two-file stored ZIP per trajectory, with metadata in records.jsonl; draft export stays blocked and file hashes are rechecked. No frame sampling/export, image conversion, cell centering or time flattening.

UI: independent bounded import form that refreshes collection without replacing current editor or selection. Sequence editor shows metadata and frame index as text, supports human review/note, and links raw bundle download. Existing rights/history controls stay authoritative.

Tests: source-derived exact fixture adapted from producer test constructor (explicit synthetic toolchain/hash provenance; no actual physics pilot), raw byte roundtrip including native float interpretation, malformed/hash/truncation/axis/stamp/nonfinite/cap/association controls, atomic failures, schema migration/history/rights/CAS, immutable family and whole-trajectory splitting, reviewed release roundtrip and browser import/inspection/review/reload/narrow layout. Run full Python, all controller tests and existing browser aggregate, respecting fixture-only qualification. No models, downloads, public writes or protected branch updates.

Independent review refinements: aggregate selected sequence assets are capped at 40 MiB before loading BLOBs. Sequence review/export permits human_reviewed only, even if an unrelated trusted verifier supplies programmatic evidence. Explicit sequence branches avoid text fallbacks in reads, tasks and asset suffixes. Migration preserves workbench_content and rejects unexpected table triggers before any change. Constructor family hashes validated native arrays with canonical zero values and excludes every association ID/version in config. See design-review.md; implementation begins only after independent review completes.
