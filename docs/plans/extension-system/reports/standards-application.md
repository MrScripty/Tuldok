Concrete consequences in this plan:

- Planning/template: one canonical path, one current phase/next slice, explicit M0
  documentation authority, future exact write sets/dependencies and separate
  documentation versus actual product acceptance. No ritual branch/commit topology.
- Architecture: complete composed-design probe; manifest packages references without
  owning numerical/runtime/access/Run authority. Representative A/B and deletion
  tests determine simplicity rather than a preferred module count.
- Contracts: closed v1 preservation, explicit project v2, independent semantic/content/
  operation/edit/schema versions, exact provider intersections and actual consumer
  matrix. New fields cannot silently widen saved v1 grammar or runtime profiles.
- Replay/persistence: full immutable material and package closure, cold data-only
  interpretation, current permissions, no latest provider or live cache substitution.
  Existing metadata owner must explicitly admit any actual DDL; no number reservation.
- IPC/security/concurrency: full variant decoding before effect, no raw mutable app
  object, current exact grants, admitted continuation semantics and unchanged Linux
  subreaper/READY–GO/receipt/drainage/unknown fence. Declared permissions are not an
  OS sandbox. Runtime profile limits and supported OS are explicit.
- Verification/oracles: source reasoning, authored fixtures, real producer/consumer,
  fresh process and domain oracle prove different claims. Negative cases must reach
  their intended discriminator and assert no downstream effects. No mocked completion.
- Frontend/accessibility: real compact dark workspace checkpoints at desktop/narrow
  widths with keyboard/numeric alternatives, stale-response exclusion and common
  structured evidence. No arbitrary extension DOM/JS or pointer/color-only result.
- Library/dependencies/licensing: source-captured minimal SDK follows a real author
  test; inert validation has no app/DB/Torch startup. No new framework, public release,
  automatic installation or invented license is selected.
- Performance/proportionality: use files/qualified encodings first; measure actual
  capture/publication/query costs before optimization. No unmeasured service target,
  shared-memory layer, GPU transfer or training campaign solely to create a plan.
- Diagnostics/privacy: passive opt-in observation remains separate from required
  audit and model evidence; no telemetry arguments or new collector activation.
