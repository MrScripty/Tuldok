## Explicit execution boundary

The caller selects private AgentClient config, trusted CLI entry-file SHA,
existing Study/trial/revision/epoch/exact grant, stable request key and expected
catalog/actor/project/graph/composition/model/runtime/Task/profile identities.
The SDK checks the immutable public material and current actor before exactly
one `studies.admit`. Existing owner operations prepare/open/approve separately;
the SDK never creates/continues/approves, exposes test, retries, cancels or starts
local training. The selected public CLI owns negotiated AgentClient contracts,
credential checks and whole-artifact segmented downloads on every call.

The checked entry source is snapshotted into a Linux sealed memfd and executed
by a fixed isolated-Python bootstrap. It never reopens the original entry path
for execution. The explicitly selected CLI installation still owns its separate
import/dependency closure. Stdlib selectors drain at most 8 MiB stdout and 64 KiB
stderr and stop/reap the client immediately on overflow or deadline. Server Run
custody remains independent and may continue after an interrupted client.

The completed Run's public evidence and every whole-hash artifact are consumed
through that same CLI. The SDK binds context/Run/composition/model/Task/profile,
checkpoint/transform/probe identities, and the common D2 Blob closure without
loading numerical state. Its machine result distinguishes `contract: passed`
from `numerical: not_evaluated`. Unknown admission acknowledgement is explicit
and never causes another mutation or request key.
