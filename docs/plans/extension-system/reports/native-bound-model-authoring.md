# Native bound model authoring

The Projects Pipeline view can inspect a Project v2 recipe through selected `recipes.inspect/2`. Only `external_model_evidence_recipe_v2` schema 3 with exact task, model, trainer, evaluator and view contributions exposes preparation. Other Project v2 data and external evidence remain inspection-only; the legacy external graph creator remains separate.

The bounded native editor uses the selected model parameter schema for Model configuration and the selected trainer plus recipe parameter definitions for separate trainer controls. It accepts only exact available Project data references matching the authored fit/probe membership. No contribution implementation or authored query callback is imported into the browser. The existing registered native model-evidence query renders admitted Run evidence.

Preparation creates and publishes a Model, creates and preflights a graph, creates a finite Study and prepares its exact immutable trial. It does not execute a Run. The owner reviews matching retained composition/Model/graph references, input membership, runtime identity, source inventory, resource envelope, finite budget, provider declarations and effective process permissions. A separate explicit approval precedes a separate Study admission. Only the acknowledged admitted Run ID can change navigation.

Provider effects/runtime/resources are the canonical inspector's hash-bound declarations. Effective permissions come from exact graph preflight: trusted-local filesystem and non-isolated network are distinct from declared effects. Completion and diagnostics do not establish model quality or physical correctness.
