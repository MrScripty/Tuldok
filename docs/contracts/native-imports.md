# Native released-data imports

Received measured bytes and declared upstream identity are distinct. Foreign review/rights are provenance, never local approval. Admission uses existing Dataset/Workbench ownership, new local IDs/draft/revision/history and unknown rights; it cannot overwrite sources. Preparation is not publication. Malformed/conflicting admissions leave existing records unchanged. Lost responses require read-only receipt reconciliation, not replay. Dirty editor and exact transient/fixed selection survive unrelated imports.

Expanded `image_caption_v1` accepts manifest, all `train/val/test/metadata.jsonl` and matching normalized PNGs. Exact rows are `file_name/text/group`; captions/components/paths/hashes must match. PNGs get new measured source identities, declared originals remain upstream evidence, and exported fixed source splits remain active. Bounds: metadata8MiB/1,000 rows, decoded signed context256KiB per row/16MiB prepared total. Originals are not reconstructed.

`native_text_import.py` accepts only native version1 stored ZIP text_classification:8MiB archive/16MiB expanded,1,000 records/2,000 outcomes,3 MiB decoded signed payload / 4 MiB encoded payload plus 65 signature/separator characters. Received canonical text is new measured input; Workbench owns canonical normalization. Original source hashes are never the new measured hash. Foreign IDs/parents become stable declared-origin group links, not local parents; omitted upstream bridges/originals remain unavailable. Active text source split is unassigned. Signed preparation is process-local/restart-invalid; committed receipts persist. Canonical text/request-marker duplicates conflict. Row-level errors remain explicit; manifest-fatal corruption refuses the archive.

`native_detection_import.py` accepts detection-only canonical_v1 stored ZIPs:1–100 records,8MiB archive/16MiB expanded,3MiB signed row/16MiB prepared total,40 million pixels per image. Negative images/fractional pixel-edge `xywh` boxes stay exact. Imported PNGs receive new identities; fixed splits and retained declared family links remain protected. Dataset owns the existing image store and atomic acquisition, with no second BLOB authority. Group overflow, decoded-pixel duplicates and split conflicts refuse rather than truncate. Targets remain drafts. This import does not infer rectangular masks, class taxonomy or segmentation truth, and is separate from any trainer-specific detection export.

[Simulation](simulation-sequences.md) and [static mesh](static-mesh.md) have their own exact profiles/bounds. Shared record ownership does not broaden the native format contracts.
