# Optional Rheon producer

This package wraps one pinned native trajectory probe as an ordinary Tuldok external
recipe. Tuldok's generic project, data, approval, and Runs owners do not import it.
Removing this package does not disable generic projects or scientific data.

Assemble a new local project from an existing qualified binary and its original
build/capture receipt:

```sh
python adapters/rheon/project.py \
  --binary /absolute/path/rheon-trajectory-probe \
  --build-receipt /absolute/path/original-receipt.json \
  --destination /absolute/path/new-project
```

The assembler creates only the new destination. It never builds, executes,
changes the original files, or overwrites an existing destination. It copies the
original receipt unchanged; that receipt supplies build evidence, not a claim
that earlier captured data was generated by the new Run. The receipt must bind
this adapter's pinned binary, lab/Rheon commits, locked build and toolchain.

Configure the new directory as an allowed project root, open `project.json`, and
select its generation recipe. Bind the `build_receipt` input to the project's
`build_receipt` data reference. The existing Pipeline controls expose grid 8–32,
frames 1–2, and seed 0–2147483647. Defaults are 32, 2, and 100. Jacobi, timestep
1/60, density 1.25, and native solver settings are fixed. Learned pressure and
SGS are not offered by this adapter.

Review the normal execution preflight and approve its exact material before
running. The generic host captures source, native policy, and inputs; the source
binary remains mode 0400. The captured wrapper seals the approved native and
loader bytes, observes loaded file identities while native READY waits for the
first command, and requests complete frames. Runs owns cancellation, descendants,
durable completion, and publication. The adapter is trusted local code, not a
filesystem or network sandbox.

A successful Run publishes `fields.zip` (role `scientific_fields`), `wire.bin`,
`producer-receipt.json`, and `native-diagnostics.txt`. Import `fields.zip` into
Data through its verified artifact action, inspect fields/frames, then separately
review and freeze it. Import parses the actual bytes; the role is only a UI hint.
The six fields preserve little-endian f32/f64 values, C-order ZYX and MAC face
staggering. Native units remain unspecified; field stages are distinct.

See [the producer contract](../../docs/contracts/rheon-producer.md). Local tests
run with `python -m unittest discover -s tests -p test_rheon_adapter.py -v`.
The two actual-native tests explicitly skip when the separately provisioned
pinned scratch build is absent. Authored parser fixtures are not native acceptance.
