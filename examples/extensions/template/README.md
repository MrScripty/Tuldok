# Inert authoring template

This is a closed task declaration, not a model or a runnable training example.
Validate with `python -m tuldok_extension_sdk validate examples/extensions/template`.

Select actual package/task identities, semantic contracts, sources and rights for
your project. When bytes change, update their declared sizes/SHA256s and immutable
project manifest reference. Never change old material to follow a new provider.
No task meaning or runtime is qualified by this template. LicenseRef-Author-Required
and NOTICE.txt are authoring slots, not permission to redistribute third-party
source/data/weights. Consult `docs/contracts/extensions.md` for the precise format.
